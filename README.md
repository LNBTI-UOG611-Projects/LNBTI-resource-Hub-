# LNBTI-resource-Hub

The proposed solution, LNBTI Help-Desk, is a centralized and responsive web-based system 
for campus resource allocation and issue management. It will provide a common platform 
through which students, lecturers, Heads of Departments, the Registrar, campus administrators, 
facilities officers, and system administrators can perform their respective activities according to 
their assigned permissions. 
The room booking and allocation module will allow students and lecturers to submit room 
requests by providing the purpose, date, time, and other required details. The request will first 
be forwarded to the relevant Head of Department for approval. Once approved, it will be 
forwarded to the Registrar, who will be responsible for allocating the room. The system will 
also support special room requests when a particular lecture room or hall is required for a 
justified reason. Subject to approval and room availability, the system will prioritize the special 
request and, where necessary, arrange an alternative room for users affected by the reallocation. 
Relevant users will be notified of allocation changes through email. 
The equipment borrowing and inventory module will use QR codes to record equipment 
collection and return. Each item or tracked equipment unit will have an associated QR code. 
Authorized users will scan the code when equipment is borrowed and scan it again when it is 

returned. The system will update the inventory records to reflect the transaction and the 
equipment's availability. 
The complaints and feedback module will allow users to submit identified complaints and 
feedback. Each submission will be recorded and assigned a status so that authorized 
administrators can review the submission, manage the required action, and monitor its progress. 
The system will incorporate role-based access control, structured database records, and status 
tracking for important requests and services. Notifications will inform users about relevant 
request updates, while administrative reports will support the monitoring of campus operations. 
The project will be developed as a responsive web application using an appropriate modern 
web technology stack and a relational database.
